# 여행길 Map Workspace v4.3

## 설계
- 검색: Kakao Local keyword + Naver Geocode API 유지
- 경로: 기존 Naver Directions 5 기반 엔진 유지. 다만 하루 방문 장소 제한만 12→30으로 변경
- 자동 시간 계산: 4곳 이하는 전수 후보 도로시간, 5곳 이상 거리 기반 휴리스틱에 실제 구간 길찾기
- 지도: fitBounds는 최초/일차전환/계산성공/사용자 전체보기에서만 실행, 기타 UI 변경은 현재 위치 보존
- 카테고리: stop.category 선택 속성 (restaurant,cafe,sight,hotel,shopping,activity,transport,other); 없으면 검색 카테고리와 장소명으로 추론
- 모바일 지도는 768px 이하 별도 화면+접이식 목록, 스크롤 충돌 방지용 초기 이동 잠금, 전체화면 보기
- 좌표는 UI만 비노출, 검색/경로 계산 데이터에는 계속 존재
- 길찾기/지도 API 호출량 증가 가능성: 30개 방문 시 방향 구간이 많으므로 서버 비용 제한과 요청량 제한 도입 권장
- 30곳/일 최적화는 전역 최적을 보장하지 않음. 실도로 접근 가능성/교통 변화는 별도 문제

## 운영 검증 체크
1. 360/390/768/1440px에서 지도, 장소 검색, 퀵칩, 드래그 및 타임라인 터치
2. 지도 길찾기 실패 시 추정 구간 레이블
3. Preview의 NAVER Maps Web URL 허용 목록과 Kakao REST API 환경변수
4. 15/30 방문지 등록 및 경로 계산 비용/응답시간 점검
5. Kakao 검색 결과 저장과 네이버 지도 표시 관련 공급자 이용약관 검토
