# STEP 1 실제 사용 영상 연결

STEP 1에는 실제 여행길 사용 화면을 보여주는 영상 자리가 준비되어 있습니다.
**현재 이 폴더에 영상이 없어도 오류나 빈 동영상 플레이어가 나타나지 않습니다.**
대신 "장소 담기 → 동선 최적화 → 지도 확인" 안내 카드가 표시됩니다.

실제 영상 준비 후 GitHub의 `feature/vnext-three-step-trip` 브랜치에
다음 파일명으로 업로드하세요:

`public/media/yeohaenggil-step1-guide.mp4`

제안 녹화 시나리오 (8~12초):
1. STEP 2에서 맛집·카페·관광지 3곳 빠르게 담기
2. '최적 동선 만들기' 버튼 누르기
3. STEP 3에서 네이버 지도 경로와 방문 순서 확인

권장 형식: MP4 (H.264, AAC 불필요/무음), 720p, 8~12초, 2~6MB.
전화번호·이메일·계정 정보·개인 여행 데이터가 나오지 않도록 주의하세요.

동작:
- 실제 MP4가 있을 때만 소스를 연결하고 자동 무음 반복 재생을 시도합니다.
- iPhone Safari용 `muted` 및 `playsinline` 적용.
- 데이터 절약 모드와 '동작 줄이기'에서는 자동 재생하지 않고 재생 버튼을 표시합니다.
- MP4가 없거나 로딩에 실패해도 날짜 선택과 STEP 2 이동은 정상입니다.
- STEP 2/3 화면에서 영상은 재생하지 않습니다.
